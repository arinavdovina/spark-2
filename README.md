# S.P.A.R.K. Conference — website v3

Current public site build.

## Main files
- `index.html` — page content
- `styles.css` — responsive design
- `script.js` — navigation and hero interaction
- `assets/` — poster and speaker photos

## v3 changes
- rebuilt speaker section to prevent text/photo overlaps;
- removed all symbols, initials and overlays from speaker photos;
- simplified speaker cards to photo + name + public bio + available links;
- removed obsolete speaker/programme CSS that could conflict with current layout;
- added defensive grid sizing (`min-width: 0`) for responsive sections;
- checked desktop, laptop, tablet and mobile layouts for horizontal overflow and direct-child collisions.
